# 🐉 D&D 5E SPIRE II: Tales of Undermountain

**던전 앤 드래곤 5판 (D&D 5e: 포가튼 렐름 - 워터딥 '하품하는 포털' & 언더마운틴 대미궁)** 세계관과 **슬레이 더 스파이어 2 (Slay the Spire 2)** 메커니즘을 결합한 덱빌딩 로그라이크 RPG입니다.

## ✨ 주요 특징
- **💻 PC 버전 (`index.html`) & 📱 모바일 전용 버전 (`mobile.html`) 2종 제공**:
  - **PC 와이드 버전 (`index.html`)**: 8클래스 한눈에 보기, 가로형 전장 및 풀사이즈 카드 핸드
  - **모바일 터치 버전 (`mobile.html`)**: 스마트폰 세로 화면 최적화, 상하 배치 전장, 좌우 터치 스와이프 카드 핸드, 하단 고정 내비게이션 독
  - 상단 헤더의 **[📱 모바일 버전]** / **[💻 PC버전]** 버튼으로 언제든 실시간 전환 가능 (세이브 데이터 100% 공유)
- **🛡️ D&D 5판 8대 클래스 × 클래스별 4개 하위 직업 (총 32가지 빌드 루트)**:
  1. **파이터 (Fighter)**: 챔피언 / 배틀마스터 / 엘드리치 나이트 / 에코 나이트 (그림자 잔상 소환)
  2. **바바리안 (Barbarian)**: 광전사 / 토템 전사(곰) / 선조의 수호자 (수호령 소환) / 야생 마법
  3. **로그 (Rogue)**: 시프 / 어쌔신 / 아케인 트릭스터 / 팬텀 (원한의 망령 소환)
  4. **레인저 (Ranger)**: 헌터 / 비스트 마스터 (흑표범 구엔위바 소환) / 글룸 스토커 / 페이 방랑자
  5. **위저드 (Wizard)**: 방출학파 / 방호학파 / 사령학파 (언데드 해골 기사 소환) / 예지학파
  6. **클레릭 (Cleric)**: 생명 권역 / 빛 권역 / 전쟁 권역 (영체 대검 수호자 소환) / 무덤 권역
  7. **팔라딘 (Paladin)**: 헌신의 맹세 / 복수의 맹세 / 정복의 맹세 (그리폰 군마 소환) / 맹세파기자 (데스나이트 소환)
  8. **워락 (Warlock)**: 마신(Fiend) 후원자 / 헥스블레이드 / 그레이트 올드 원 / 사슬의 군주
- **🏰 5개 계층 (Act 1 ~ 5) × 층별 30개 스테이지 (총 150 스테이지)**:
  - 각 층마다 **4종류의 고유 보스 (총 20종 D&D 보스)** 중 1명이 매 판 무작위로 배정됩니다.
